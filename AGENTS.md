# Repository instructions

## Commit attribution

For commits containing work authored or substantially modified by Codex, keep the user's Git author identity and include this trailer exactly once in the final trailer block:

```text
Co-authored-by: Codex <noreply@openai.com>
```

Separate the trailer block from the commit description with a blank line. Preserve existing co-author and sign-off trailers.

Apply this rule to future Codex-assisted commits. Do not add Codex attribution to unrelated work or rewrite existing commits solely to add attribution.
